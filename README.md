# Pokémon Web

Projeto acadêmico desenvolvido para a faculdade por **Rônero G. Cavalcante**.

Aplicação web em Spring Boot com Thymeleaf e PostgreSQL.

## Como rodar

Requisitos: Docker e Java 21.

```bash
# sobe o banco PostgreSQL
docker compose up -d

# inicia a aplicação
./mvnw spring-boot:run
```

Depois é só acessar http://localhost:8080.
